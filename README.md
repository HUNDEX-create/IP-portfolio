# Hundaol Begna Telbaso — Personal Portfolio

A personal portfolio website developed as part of **Internet Programming I**. The project showcases my background, academic journey, technical skills, programming projects, and understanding of modern HTML5 features.

---

## About the Project

This portfolio was developed to apply the fundamental concepts of HTML5 through a practical, multi-page website.

It brings together personal information, academic records, technical skills, project descriptions, and contact information in a structured and accessible format.

The project also demonstrates how semantic HTML, forms, interactive elements, multimedia, and the HTML Canvas API can be used to create a richer web experience.

## Features and HTML5 Concepts

The website demonstrates the following concepts:

- **Semantic HTML5:** Meaningful page structure using elements such as `header`, `nav`, `main`, `section`, `article`, and `footer`.
- **Text and Content Formatting:** Headings, paragraphs, lists, links, abbreviations, and special characters.
- **Images and Navigation:** Images, hyperlinks, and organized navigation between pages.
- **HTML Forms:** Contact form elements, labels, fieldsets, input types, and validation attributes.
- **Interactive Elements:** Native HTML elements such as `details`, `summary`, and `dialog`.
- **Date and Time Elements:** The HTML `time` element for meaningful date representation.
- **Progress and Measurement:** HTML `progress` and `meter` elements.
- **HTML Canvas:** A logo and graphical representation of technical skills using JavaScript and Canvas.
- **Multimedia Preparation:** Video and audio sections prepared for the relevant media resources.

## Website Pages

### 1. Homepage — `index.html`

The homepage introduces me and provides an overview of my personal and academic background.

It includes:

- Personal introduction and profile image.
- Academic background and educational records.
- Technical skills and areas of interest.
- Project highlights.
- Contact information and contact form.
- Interactive HTML5 elements and Canvas graphics.

### 2. Projects Page — `projects.html`

This page presents selected programming projects and provides additional information about their development.

Featured projects include:

Each project includes a description, relevant technologies, and development information.

### 3. Thank You Page — `thank-you.html`

## Running the Project Locally

You can view the portfolio on your computer by following these steps:

1. Clone the repository:

   ```bash
   git clone https://github.com/HUNDEX-create/IP-portfolio.git
   ```

2. Open the project folder:

   ```bash
   cd IP-portfolio
   ```

3. Open `index.html` in your web browser.

You can also open the project folder in Visual Studio Code and use the Live Server extension for local development.

## Important Note About the Contact Form

The contact form demonstrates HTML5 form structure and validation. However, a static website hosted on GitHub Pages cannot independently process server-side form submissions.

A backend service or form-processing endpoint is required to make actual message delivery work.
