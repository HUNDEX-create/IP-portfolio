
# Hundaol Begna Telbaso — Personal Portfolio

## About the Project

This is my personal portfolio website developed as part
of the Internet Programming I course.

The project demonstrates fundamental HTML5 concepts,
including document structure, text formatting, hyperlinks,
images, image maps, lists, and tables.
